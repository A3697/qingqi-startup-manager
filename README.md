# 轻启 · QingQi

Windows 软件启动与窗口管理器。按顺序启动软件，也可以沿用软件原有自启动，只处理窗口。

**便携版，C# / WinForms / .NET Framework 4.8，无 NuGet 运行依赖。** 不安装服务，不注入目标进程，不修改被管理软件本体。

## 原始参考项目

轻启是在独立 C# 启动器基础上实现的项目，**不是以下项目的直接 fork**。设计与实现时参考：

| 原始项目 | 许可证 | 参考范围 |
| --- | --- | --- |
| [Faustvii/StartupManager](https://github.com/Faustvii/StartupManager) | MIT | Windows 自启动来源分类与只读扫描思路 |
| [AlexanderPro/SmartSystemMenu](https://github.com/AlexanderPro/SmartSystemMenu) | MIT | Win32 窗口枚举、窗口显示状态和进程优先级设计 |

没有纳入上述项目的第三方自启动禁用/删除功能，也没有纳入全局 Hook 或注入模块。完整许可证与功能比较来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和 [references](references)。

## 下载与使用

从 [Releases](../../releases) 下载 `QingQi-2.4.0-portable.zip`，解压到可写目录（例如 `D:\QingQi`），运行 `轻启.exe`。保留同目录的核心 DLL 和托盘助手；第一次运行自动创建 `data`。

1. 点击 **添加软件…**：先搜索软件列表；找不到时点击弹窗中的 **选择软件路径…**，选择 EXE 或快捷方式。
2. 为每个软件选择启动方式、启动顺序、启动前等待和窗口模式。数字较小的先启动，相同数字按添加顺序。
3. 根据需要开启 **登录后执行规则**，以及 **执行完成后退出主程序**。
4. 点击 **执行全部已启用规则**。选中行呈蓝色；双击可编辑；点击空白处取消选择。

软件列表来自开始菜单、桌面快捷方式、已登记自启动和运行窗口，不承诺枚举所有安装软件。设置中的 CPU 优先级影响进程调度，与启动顺序独立。

### 保留原自启动

选择 **沿用软件原自启动** 后，轻启不主动启动该软件，仅等待其窗口。读取 Run、启动文件夹和登录/开机计划任务，不修改第三方登记。未检测到登记时，该选项呈灰色；Windows 已禁用的登记仍需自行启用。

轻启自己的登录启动开关只修改当前用户的 `Run\QingQiStartupManager` 及其对应启用状态。移动便携目录前先关闭该开关，移动后重新开启。已有程序按完整 EXE 路径检测，避免重复拉起；同一个启动 EXE 只能配置一条规则。

### 窗口模式

| 模式 | 行为 |
| --- | --- |
| 正常显示（沿用软件） | 保持软件自己的窗口行为 |
| 最大化 | 展开窗口 |
| 最小化 | 保留任务栏按钮 |
| 最小化到托盘 | 收起任务栏窗口，保留恢复入口 |
| 打开窗口后最小化 | 展开并停留指定秒数后收起到任务栏 |
| 打开窗口后最小化到托盘 | 展开并停留指定秒数后收起到托盘 |

**已有原生托盘图标时不再新建图标。** 先尝试软件原生最小化；若没有进入托盘，默认保留窗口并提示配置。逐软件验证原图标能恢复隐藏窗口后，可打开 **原生最小化无效时隐藏窗口**。此补充处理只有检测到实际原图标时才生效，更换窗口程序会清除确认。

没有原生图标的软件，由轻启提供每个软件独立的恢复图标，并保留轻量托盘助手。恢复全部窗口或目标退出后助手退出；助手不会另建一个统一的托盘图标。主程序和助手使用不同图标。

窗口观察时间决定本轮等待新窗口出现的时长，不会长期压制软件后来弹出的窗口。已开始的“打开后停留”会完成。点击 **停止本轮后续操作** 会停止剩余启动和后续窗口处理，已经托管的窗口仍保留恢复入口。

## 环境与边界

- Windows 10/11 桌面环境，.NET Framework 4.8。2.4.0 的桌面验收环境为 Windows 11 x64、150% 缩放；其他系统尚未实机验收。
- 普通权限不能保证操作管理员权限软件或特殊宿主窗口。程序不会自动提权。
- 第三方软件可能短暂显示窗口、拒绝控制或稍后自行改变窗口状态。自动托盘识别依赖 Windows 提供的图标登记与活动图标核验；特殊实现需手动指定原生图标。
- 原生图标在观察期间消失时提供恢复保障。助手退出后不持续监控原图标；必要时重新打开轻启，使用 **恢复此软件窗口**。
- 设置和恢复记录保存在本地 `data`，不包含遥测、云端同步或自动更新。升级时保留整个 `data` 文件夹。

## 构建与测试

在 Windows 上用 PowerShell 7 执行：

```powershell
pwsh -File .\build.ps1
pwsh -File .\verification\Test-All.ps1
pwsh -File .\package.ps1
```

编译使用系统 .NET Framework C# 编译器，输出到 `release`。打包脚本只选取产品文件、说明和许可证，输出到 `dist`，不带本机配置。源码可在 Visual Studio 等编辑器中查看，无须安装 SDK 或下载 NuGet 包。

完整测试需要已登录的交互式 Windows 桌面，会短暂显示自动退出的测试窗口；请勿操作这些测试窗口。测试只对隔离的测试程序施加窗口控制，读取本机自启动登记并核对其未变更，不注册测试程序自启动。界面测试要求至少存在一项可读取且 EXE 存在的自启动登记。历史测试文件名中的版本号表示用例引入版本；执行入口统一为 `Test-All.ps1`。

验收范围和未覆盖事项见 [docs/TESTING.md](docs/TESTING.md)。本次未进行主动重启电脑后的冷启动测试。

## 文件与恢复

| 文件 | 用途 |
| --- | --- |
| `轻启.exe` | 管理界面与规则执行 |
| `轻启托盘助手.exe` | 临时窗口处理、无原生图标时保留恢复入口 |
| `QingQi.Core.dll` | 核心逻辑 |
| `data/配置.json` | 软件规则和全局设置，写入保留 `.bak` |
| `data/托盘窗口.json` | 按句柄、进程创建时间和路径校验的窗口恢复记录 |
| `data/最近运行.json`、`data/运行日志.txt` | 执行结果与本地日志 |

列表中移除软件只移除轻启规则并请求恢复窗口，不卸载软件。卸载轻启前先关闭登录启动、恢复轻启托管窗口，再退出并移除便携目录。配置损坏时保留原文件并报错，不以空配置覆盖。
