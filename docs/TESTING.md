## 桌面与安装验收

- 主界面、规则页和高级设置实际显示清楚，选中状态呈蓝色，按钮明确写出作用对象和行为；未登记原自启动的选项呈灰色并说明原因。
- 实测搜索无结果、手选 EXE、添加保存、放弃修改、移除规则、点击空白取消选择，以及最大化、最小化后恢复。未再观察到旧版透明透出桌面的问题。
- 主程序蓝色图标与助手青色图标分别可辨；软件列表读取目标 EXE 图标。
- D 盘便携安装升级保留原配置；轻启自身登录开关关闭/开启后恢复原登记状态。第三方自启动仍只读。

## 本轮修复

1. 原生托盘交接在取消后继续隐藏窗口。
2. 路径 A → B → A 往返错误沿用 B 的托盘恢复确认。
3. 日志文件并发写入或独占导致界面读取异常。
4. 同一数据目录带尾部分隔符时单实例标识不一致。
5. 对话框内编辑路径绕过重复软件规则检查；保存失败时恢复原内存列表。
6. 导入弹窗未选中时添加按钮状态不明确、顶部说明显示空间不足；主表区分启动顺序、启动前等待和窗口观察时间。

## 验收边界

未主动重启电脑进行冷启动测试；未测试其他 Windows 版本、多显示器混合 DPI、受保护的管理员窗口或所有第三方软件。通过本机回归不等于任意软件均支持窗口控制。原生图标退出后的异常由持久化恢复记录兜底，不保留常驻监控进程。
