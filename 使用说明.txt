轻启 · 自启动管理器 2.4

打开“轻启.exe”即可管理。解压到可写目录（例如 D:\QingQi）；需要 Windows 的 .NET Framework 4.8。
请保留同目录的 QingQi.Core.dll、轻启托盘助手.exe 和 data 文件夹。

添加软件
点击“添加软件…”先打开可搜索的软件列表，来源包括开始菜单、桌面快捷方式、已登记自启动和正在运行的窗口。
列表里找不到时，在同一弹窗点击“选择软件路径…”，选择 EXE 或指向 EXE 的快捷方式。
点击“添加已有自启动软件…”可读取 Run、启动文件夹及登录/开机计划任务，默认选择“沿用软件原自启动”。
未检测到原自启动登记时，该启动方式显示为灰色，不可新选。Windows 已禁用的原启动项仍需在原软件或 Windows 中启用。
历史跟随规则即使原登记已丢失，也不会被擅自改成主动启动；改选为另一个未登记的 EXE 时使用“由轻启启动”。
轻启不会更改第三方 Run 值、计划任务、启动文件夹内容、软件设置或软件本体。

独立设置
启用开关向右、蓝色表示开启；向左、灰色表示关闭。全局开关也使用同样的滑轨形式。
深蓝底白字的一行表示当前选择，下方同时显示软件名称。点击列表空白或界面空白处取消选择，相应操作按钮变灰。
双击一行或点击“编辑此软件的规则…”，可为每个软件设置：
- 启动方式：由轻启启动 / 保留原自启动。
- 启动优先级：数字越小越先启动；相同数字按添加顺序。
- 启动前等待：轮到该软件时等待的秒数，按顺序累计。已在运行则跳过，不重复启动。
- 窗口模式：正常显示、最大化、最小化、最小化到托盘、打开窗口后最小化、打开窗口后最小化到托盘。
- 打开后停留：两种“打开窗口后……”模式独立使用的停留秒数。
- 参数、工作目录、实际窗口程序，以及可选 CPU 进程优先级。
“启动优先级”控制顺序；“CPU 优先级”控制运行调度。两者独立。
跟随原自启动的软件不由轻启安排启动先后；其顺序和启动条件保持原样。

窗口与托盘
最小化：窗口留在任务栏。
最小化到托盘分两种情况：
- 已有原生图标：调用软件自己的最小化行为，由软件按其原生配置收起。确认收起后不保留轻启恢复记录，也不增加该软件的托盘图标。
- 没有原生图标：轻启先提供恢复图标，再收起窗口；轻量助手保留图标，软件继续运行。
如果软件原生最小化不能收起到托盘，默认保留任务栏窗口并提示。确认原托盘图标可以恢复被隐藏的窗口后，可在该软件规则中开启“原生最小化无效时隐藏窗口”。此选项仅在实际检测到原图标时生效：隐藏任务栏窗口，沿用原图标恢复，不增加图标。
每个软件均需先验证原图标能恢复隐藏窗口，再开启补充处理。更换实际窗口程序后确认会清除。
补充隐藏会保留精确窗口恢复记录；助手退出后仍可从管理界面点击“恢复此软件窗口”。不发送关闭或结束进程命令。
原生图标稍后出现时，先恢复确认窗口可访问，再尝试原生收起，最后释放轻启恢复入口。软件响应缓慢时，交接前已有的恢复图标会保留到恢复确认。
数值 UID 和 GUID 原生图标均支持识别。原生托盘窗口通过软件自己的图标恢复；轻启托管的窗口可点击恢复图标或主界面的“恢复此软件窗口”。
若特殊软件的自带图标未识别，可在规则中开启“此软件自带托盘图标（手动指定）”。
自动检测使用本机 Windows 的图标登记和活动图标核验；其他系统或特殊图标实现可使用上述兼容选项。

启动器是否退出
“执行完成后退出主程序”可用滑轨开关开启或关闭，全局选项立即自动保存。
软件规则的蓝色带勾选项表示当前选择；修改后点击“保存此软件规则”。“放弃修改”不保存。
开启后：启动和窗口观察完成后，轻启主程序退出。
原生托盘软件不需要助手常驻。如果仍有无原生托盘的软件被轻启收起，独立的轻量助手继续提供恢复入口；不会额外显示一个统一的“窗口助手”图标。
观察期间或退出前发现原生恢复图标消失，会保留轻启恢复入口；助手退出后不持续监控原图标。原图标异常时可重新打开轻启并恢复窗口。
全部托盘窗口恢复或对应软件退出后，助手自动退出。
每个轻启恢复图标的右键菜单都提供“恢复全部窗口并退出助手”。
登录自动执行时若原生托盘需要配置，轻启会短暂显示通知；主动打开查看通知会保留管理界面，未查看则按设置退出。最近结果在下次打开时仍可查看。
关闭自动退出时：主程序保留，可从其托盘图标打开界面；没有周期性重启软件的功能。

窗口观察
观察秒数决定本轮继续寻找新窗口的时间；启动较慢的软件可调大，最多 600 秒。
已经发现的窗口会完成配置的“打开后停留”再收起。
观察结束后不会持续压制软件以后新弹出的窗口。
用户通过轻启恢复的窗口，不会在同一轮任务中再次被收起。
软件通过自身托盘等方式重新显示窗口，也会释放轻启提供的恢复入口。
窗口响应慢时，助手会保留恢复记录直到确认已恢复；结果中的“窗口失败”与“启动失败”分别统计。
软件可能短暂显示窗口后才被处理；第三方程序再次改变自己的窗口状态不一定可阻止。
普通权限不能保证控制管理员权限或特殊宿主窗口。
如果启动程序是更新器或前置启动器，请在“窗口所属 EXE”中选择实际拥有窗口的程序。
匹配按完整 EXE 路径和当前 Windows 会话；同一路径的多个窗口会作为同一个软件处理。

自启动设置
“登录 Windows 后执行规则”只管理轻启自己的当前用户 Run 项：
HKCU\Software\Microsoft\Windows\CurrentVersion\Run\QingQiStartupManager
Windows 可能延后运行登录启动项。
关闭轻启自启动不影响第三方软件原有自启动。
移动便携目录前，先从原位置关闭轻启自启动，移动后再重新启用。

数据与恢复
data\配置.json：设置；写入时保留 .bak。
data\运行日志.txt：执行结果；上限约 500 KB，轮换保留一份 previous。
data\托盘窗口.json：窗口恢复记录，按窗口句柄、进程、创建时间和完整路径校验身份。
data\最近运行.json：最近一轮执行结果。
配置格式异常时会停止读取，保留原配置，不会用空列表覆盖。
从列表移出软件时只移除轻启中的配置，并请求恢复窗口；不会删除软件或其原自启动。
